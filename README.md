# Lujon Flowers — joniz-flower-shop

Premium multi-page website for **Lujon Flowers**, an artisan florist in Tirana, Albania.

- Static site — plain HTML, CSS, JS (no build step).
- Bilingual: Albanian (default) + English toggle.
- Pages: Home, Shop, Product, Prices & Delivery, Weddings, About, Contact.
- WhatsApp / call ordering, full technical SEO (schema, sitemap, robots), mobile-optimized.

## Deploy (Vercel)
1. Push this repo to GitHub.
2. In Vercel: **Add New → Project → Import** this repo.
3. Framework Preset: **Other**. Root: `/`. Deploy.
4. Add the custom domain **lujon-flowers.com** in Project → Settings → Domains.

No build command or output directory needed — it's static.
